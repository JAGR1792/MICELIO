# Micelio Syntax

Extensión de VS Code para el lenguaje de programación Micelio.

## Características

- **Resaltado de sintaxis** para archivos `.mice` y `.micelio`
- **Snippets** para funciones, condicionales, bucles, matrices, redes neuronales y más
- **Autocompletado** de palabras clave, funciones builtin, símbolos locales y miembros de módulos importados
- **Información al hover** con documentación de funciones y palabras clave
- **Ayuda de firmas** con parámetros de funciones builtin
- **Esquema de documento** (outline) con funciones y variables
- **Ir a definición** para funciones y variables locales y de módulos importados
- **Pipe operator** (`|>`) con indentación automática al presionar Enter
