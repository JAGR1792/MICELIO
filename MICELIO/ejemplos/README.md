# Ejemplos didacticos de Micelio

Este directorio agrupa ejemplos cortos y ejecutables por modulo.

## Graficos
- `19_grafico_simple.mice`: grafo simple con nodos y aristas en español.
- `20_grafico_seno_coseno.mice`: seno y coseno superpuestos con leyenda.
- `21_grafico_histograma.mice`: histograma basico de una muestra aleatoria.

## Modulos base
- `22_math_didactico.mice`: funciones matematicas basicas.
- `23_lista_didactica.mice`: utilidades de listas.
- `24_dict_didactico.mice`: combinacion y transformacion de diccionarios.
- `25_set_didactico.mice`: operaciones de conjuntos.
- `26_matriz_didactica.mice`: operaciones de matrices.
- `27_archivo_didactico.mice`: lectura, escritura y borrado de archivos.
- `28_ml_didactico.mice`: regresion lineal y division de datos.
- `29_dl_didactico.mice`: entrenamiento minimo con checkpoints.
- `30_gui_didactico.mice`: estado y estilos del modulo GUI.
- `31_hifa_didactico.mice`: creacion y definicion de rutas web.
